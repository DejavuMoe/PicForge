# PicForge

ブラウザーで動くオープンソースの画像ツールです。画像の圧縮・リサイズ、Android モーションフォトの分離、iOS Live Photos の JPEG・MP4 変換に対応します。ファイルは端末の外へ送信されません。

[PicForge を開く](https://picforge.de) · [English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md)

## ツールを選ぶ

| ツール | 入力 | 出力 |
| --- | --- | --- |
| 画像圧縮 | JPEG、PNG、WebP、AVIF などの対応画像 | JPEG、WebP、PNG、AVIF。まとめてサイズ変更も可能 |
| Android モーションフォト | 動画を含むオリジナルの JPG | 再エンコードせずに元の JPG + MP4 を抽出 |
| iOS Live Photos | HEIC/HEIF + MOV。写真・動画単体も対応 | JPEG + H.264 MP4。音声の保持を選択可能 |

登録・インストール・アップロードは不要です。テレメトリーはありません。アプリの静的ファイルと処理エンジンは取得しますが、メディアの処理はブラウザーのローカルメモリー内で完結します。

## 使い方

1. ホームでツールを選択します。**この画像で試す** を押すと、個人データを含まない生成サンプルを実際の圧縮処理で試せます。
2. ファイルを追加します。画像圧縮はドラッグ＆ドロップと貼り付けにも対応します。Live Photos は同名の写真と動画を一緒に追加してください。
3. 設定を調整します。画像は自動処理、モーションフォトと Live Photos はバッチ操作で開始します。
4. 元画像と結果を比較し、ズームで細部を確認して保存します。単体保存と一括 ZIP に対応し、ZIP にはマニフェストが含まれます。

**設定の範囲。** 全画像の設定は共有設定です。この画像の設定は完全な独立コピーになります。共有設定の変更では個別設定は上書きされず、共有設定に戻す操作が必要です。

**リサイズ。** 範囲内に合わせる場合は縦横比を維持し、拡大しません。中央クロップは指定サイズを埋め、ストレッチは指定の幅と高さを使います。割合指定は詳細設定にあります。数値入力は Enter またはフォーカスを外すと反映され、Escape で取り消せます。PNG は可逆圧縮のため画質スライダーを使いません。

**キュー。** ツールの切り替え、ホームへの移動、ブラウザーの戻る・進む操作では現在のキューを保持します。再読み込みやページを閉じると消えるため、先に保存してください。スマートフォンではファイルを選んでプレビューへ進み、設定は画像の下に表示されます。一括操作は常にアクセスできます。

## 対応範囲

- Android の抽出は元のバイト列を保持します。動画の再生可否は内部コーデック次第ですが、再生できなくてもダウンロードできます。
- iOS の組み合わせはファイル名に基づき、Apple のアセット識別子は照合しません。重複名は解決が必要です。出力は共有用であり、HEIC のメタデータ、HDR、補助画像を保持するアーカイブではありません。
- 動画の時間情報は既定で保持し、30 fps も選択できます。現在の FFmpeg には表示範囲のクロップと回転を補正するアダプターがあります。
- Worker 数、ファイルサイズ、画素数には上限があります。大きすぎるファイルは拒否される場合があります。キャンセル・再試行には元ファイルを使います。
- オフライン利用にはアプリ資産のキャッシュが必要です。大型変換エンジンは正常な読み込みとキャッシュ後に利用できるため、初回変換では接続が必要な場合があります。
- 言語はブラウザーに合わせ、未対応なら英語を使用します。選択した言語とテーマは保存可能な場合に端末へ保存します。保存を禁止していても、その訪問中の切り替えは動作します。5 言語とライト／ダークテーマに対応します。

## ローカル開発

Node.js **22.12.0 以上**、pnpm **11.8.x** が必要です。

```sh
git clone https://github.com/DejavuMoe/PicForge.git
cd PicForge
pnpm install
pnpm dev
```

`http://127.0.0.1:5173` を開きます。`pnpm build` でビルドし、`pnpm preview` で確認します。コーデックは `/wasm/` から自己ホストされ、処理サーバーや API キーは不要です。

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
# 開発サーバーを起動した状態で UI を検証
PICFORGE_UI_GROUPS=entry,layout,interaction,usability node scripts/ui-check.mjs
pnpm test:browser
```

UI 検証は `PICFORGE_UI_BROWSER=chromium|firefox|webkit` を指定でき、成果物は一時ディレクトリーへ保存されます。メディア検証には `ffprobe`、合成変換サンプルには `heif-enc` と `ffmpeg` が別途必要です。個人のカメラファイルをコミットしないでください。

本番の圧縮処理は `@jsquash/*` の互換エンジンを使用します。wasm-vips は実験段階です。React と標準 HTML/CSS を使い、変換エンジンと ZIP ライブラリーは必要時に読み込みます。[UI と検証](../UI_DESIGN.md)、[QA](../QA_CHECKLIST.md)、[過去のメディア検証](../SAMPLE_VALIDATION.md)、[今後の計画](../next-steps-plan.md)を参照してください。Playwright WebKit は実機 Safari／iPhone の検証とは異なります。異なる環境の性能数値を直接比較しないでください。
