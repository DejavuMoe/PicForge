# PicForge

브라우저에서 실행되는 오픈 소스 이미지 도구입니다. 이미지를 압축하고 크기를 조절하며, Android 모션 포토를 분리하고 iOS 라이브 포토 원본을 JPEG와 MP4로 변환합니다. 파일은 기기에 그대로 남습니다.

[PicForge 열기](https://picforge.de) · [English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

## 도구 선택

| 도구 | 입력 | 출력 |
| --- | --- | --- |
| 이미지 압축 | JPEG, PNG, WebP, AVIF 등 지원 이미지 | JPEG, WebP, PNG 또는 AVIF. 일괄 크기 조절 가능 |
| Android 모션 포토 | 동영상이 포함된 원본 JPG | 재인코딩 없이 원본 JPG + MP4 추출 |
| iOS 라이브 포토 | HEIC/HEIF + MOV. 사진과 동영상 단독 처리도 가능 | JPEG + H.264 MP4. 오디오 유지 선택 가능 |

가입, 설치, 업로드가 필요 없으며 원격 측정도 없습니다. 앱의 정적 파일과 처리 엔진은 내려받지만, 미디어 처리는 브라우저의 로컬 메모리에서 이루어집니다.

## 사용 방법

1. 홈에서 도구를 선택하세요. **예제 사용**를 누르면 개인 정보가 없는 생성 예제로 실제 압축을 실행할 수 있습니다.
2. 파일을 추가하세요. 이미지 압축은 드래그 앤 드롭과 붙여넣기를 지원합니다. 라이브 포토는 이름이 같은 사진과 동영상을 함께 추가하세요.
3. 설정을 조절하세요. 이미지는 자동으로 처리하며 모션 포토와 라이브 포토는 일괄 처리 버튼으로 시작합니다.
4. 원본과 결과를 비교하고 확대해 디테일을 확인한 뒤 다운로드하세요. 개별 저장과 일괄 ZIP을 지원하며 ZIP에는 매니페스트가 포함됩니다.

**설정 범위.** 전체 이미지 설정은 공유됩니다. 이 이미지 설정은 완전한 독립 사본입니다. 전체 설정을 변경해도 개별 설정은 유지되며, 공유 설정으로 돌아가는 동작을 명시적으로 선택해야 합니다.

**크기 조절.** 경계에 맞추기는 비율을 유지하고 원본을 확대하지 않습니다. 가운데 자르기는 지정한 크기를 채우며, 늘이기는 정확한 너비와 높이를 적용합니다. 백분율은 고급 설정에 있습니다. 숫자는 Enter를 누르거나 입력란을 떠날 때 적용하고 Escape로 취소합니다. PNG는 무손실 압축이므로 품질 슬라이더를 사용하지 않습니다.

**대기열.** 도구 전환, 홈 이동, 브라우저 뒤로/앞으로 이동 시 현재 세션의 대기열은 유지됩니다. 새로고침하거나 페이지를 닫으면 파일과 결과가 사라지므로 먼저 다운로드하세요. 모바일에서는 파일을 선택해 미리보기로 이동하며 설정은 이미지 아래에 표시됩니다. 일괄 작업은 계속 접근할 수 있습니다.

## 지원 범위

- Android 추출은 원본 바이트를 보존합니다. 동영상 미리보기는 내장 코덱에 따라 달라지며 재생할 수 없어도 다운로드할 수 있습니다.
- iOS는 파일 이름으로 짝을 맞추며 Apple 자산 식별자는 검증하지 않습니다. 중복 이름은 해결해야 합니다. 출력은 공유용이며 HEIC 메타데이터, HDR, 보조 이미지를 보존하는 아카이브가 아닙니다.
- 동영상은 기본적으로 원본 타임스탬프를 유지하며 30 fps도 선택할 수 있습니다. 현재 FFmpeg에는 표시 영역 자르기와 회전을 위한 어댑터가 적용됩니다.
- Worker 수, 파일 크기, 픽셀 수에 제한이 있습니다. 너무 큰 파일은 거부될 수 있습니다. 취소와 재시도는 원본 파일을 유지합니다.
- 오프라인 사용에는 앱 자산 캐시가 필요합니다. 대형 변환 엔진은 정상적으로 로드하고 캐시한 후에만 오프라인에서 사용할 수 있어 첫 변환에는 연결이 필요할 수 있습니다.
- 언어는 브라우저 설정을 따르며 지원하지 않으면 영어로 표시됩니다. 명시적으로 선택한 언어와 테마는 허용된 경우 로컬에 저장합니다. 저장소가 차단돼도 현재 방문 중에는 전환할 수 있습니다. 5개 언어와 밝은/어두운 테마를 지원합니다.

## 로컬 개발

Node.js **22.12.0 이상**, pnpm **11.8.x**가 필요합니다.

```sh
git clone https://github.com/DejavuMoe/PicForge.git
cd PicForge
pnpm install
pnpm dev
```

`http://127.0.0.1:5173`을 여세요. `pnpm build`로 빌드하고 `pnpm preview`로 확인합니다. 코덱은 `/wasm/`에서 자체 호스팅하며 처리 서버나 API 키가 필요 없습니다.

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
# 개발 서버가 실행 중일 때 UI 검사
PICFORGE_UI_GROUPS=entry,layout,interaction,usability node scripts/ui-check.mjs
pnpm test:browser
```

UI 검사는 `PICFORGE_UI_BROWSER=chromium|firefox|webkit`을 지원하며 증거는 임시 폴더에 저장합니다. 미디어 검증에는 `ffprobe`, 합성 변환 샘플에는 `heif-enc`와 `ffmpeg`가 추가로 필요합니다. 개인 카메라 파일을 커밋하지 마세요.

운영 압축 경로는 `@jsquash/*` 호환 엔진을 유지합니다. wasm-vips는 실험 단계입니다. React와 표준 HTML/CSS를 사용하고 변환 엔진과 ZIP 라이브러리는 필요할 때 로드합니다. [UI와 검증](../UI_DESIGN.md), [QA](../QA_CHECKLIST.md), [기존 미디어 검증](../SAMPLE_VALIDATION.md), [다음 계획](../next-steps-plan.md)을 참고하세요. Playwright WebKit 검사는 실제 Safari/iPhone 검증과 다르며, 서로 다른 호스트의 성능 수치를 직접 비교하면 안 됩니다.
